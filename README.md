# Dojo Helpdesk

A helpdesk application built while learning Next.js.

## About
Built following a Next.js tutorial (https://netninja.dev/p/next-13-masterclass), independently adapting 
the codebase from Next.js 13 to Next.js 14 App Router 
conventions and resolving breaking changes along the way.

## Tech Stack
- Next.js 14 (App Router)
- JavaScript
- Tailwind CSS
- Supabase (authentication & database)

## Key Learning
- Next.js App Router migration from Pages Router
- Supabase authentication and database integration
- Middleware implementation
